📱 Buffer — TikTok + Instagram + Threads
Buffer posts your vertical video (1080×1920) to all connected social channels automatically.
Connect TikTok, Instagram, and Threads inside Buffer first, then add your API key here.
Buffer API Key Posts TikTok + Instagram + Threads
publish.buffer.com → Settings → API → Create Token
How to connect Buffer
1. Go to buffer.com → Create free account
2. Click Add Channel → Connect TikTok → log in
3. Click Add Channel → Connect Instagram → log in
4. Click Add Channel → Connect Threads → log in
5. Go to publish.buffer.com/settings/api → Create Token
6. Paste the token above → Save
